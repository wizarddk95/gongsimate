# isu_petasys_v0_2

v0.1 평가셋과 v0.1 실행 결과는 수정하지 않는다. 검색기, 청킹, 토크나이저, BM25 파라미터, 인덱스 범위, 질문 문장도 바꾸지 않는다.

## v0.2

- Q07 retrieval gold를 단일 derived operand path에서 alternative evidence path로 확장했다.
- `direct_reported_metric`: IV. 이사의 경영진단 및 분석의견 > 3. 재무상태 및 영업실적 > 2) 수익성지표의 연결 매출액영업이익률. 당기 18.82%, 전기 12.17%. 연결 범위는 바로 앞 문장 `(연결기준)`에 있다.
- `derived_operands`: 기존 연결 포괄손익계산서 원값 4개를 유지한다. 이 경로는 삭제하지 않는다.
- 두 경로를 동시에 요구하지 않는다. 한쪽이 전부 회수되면 retrieval answer evidence는 성공이다.
- deterministic calculation 테스트는 derived operand 경로만 사용한다. 원값으로 계산한 표시 차이는 +6.64%p이고, 기재된 18.82와 12.17을 빼면 +6.65%p이다. 두 정밀도 정책은 바꾸어 쓰지 않는다.
- Q07-A1, Q07-A2는 legacy `claim_set_recall` 분모에 넣지 않는다. 그 분모는 여전히 required claim의 AND이다.
- Q01~Q06, Q08~Q10의 gold와 E186 hard negative 정책은 v0.1과 같다.

## 왜 Path A를 인정하는가

수익성지표 표의 행 이름은 `매출액영업이익률`이고 산식은 `영업이익/매출액×100`이다. Q07이 묻는 연결 영업이익률과 같은 정의다. 표 열은 `당 기`/`전 기`이고, 같은 절의 `주요경영지표입니다.(연결기준)`이 연결 범위와 당기·전기를 붙인다. 같은 절 요약 연결손익계산서의 `2025년도(제54기)` / `2024년도(제53기)` 열이 그 당기·전기를 FY2025·FY2024에 대응시킨다. 이 연도 헤더는 검수 근거이며 Path A의 검색 필수 span은 아니다.
